## Deployment

GitHub Pages를 통해 정적 웹사이트로 배포합니다.

### 프로젝트 구조

```text
/(root)
├── README.md
├── index.html
└── portfolio.pdf
```

### 배포 방법

1. GitHub 저장소에 `index.html`과 `portfolio.pdf`를 업로드합니다.
2. 저장소의 `Settings → Pages`로 이동합니다.
3. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 설정하고 저장합니다.
5. 배포가 완료되면 GitHub Pages 주소에서 포트폴리오를 확인할 수 있습니다.
